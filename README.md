# 🎮 坦克大战 Tank Battle

一个使用原生 HTML5 Canvas 编写的经典坦克大战（Battle City）游戏，单文件即可运行，无需任何依赖。

## ✨ 功能

- 🕹️ 键盘 + 触屏（移动端）双操控
- 🧱 可破坏的砖墙、不可破坏的钢墙、水面、草丛地形
- 🦅 需要保卫的基地（老鹰）
- 🤖 会移动、会瞄准射击的敌方坦克
- 💥 爆炸粒子特效与 8-bit 风格音效（Web Audio）
- 🎁 三种道具：护盾 / 加命 / 火力强化
- 📈 无限关卡，难度逐步提升
- 🏆 最高分本地存档（localStorage）

## 🚀 运行

直接双击打开 `index.html`，或在浏览器中打开它即可。

## 🎮 操作

| 操作 | 按键 |
|------|------|
| 移动 | `W A S D` 或 `↑ ← ↓ →` |
| 射击 | `空格` 或 `J` |
| 开始 | `Enter` |
| 暂停 / 继续 | `P` |

移动端会自动显示虚拟方向键与开火按钮。

## 📁 文件结构

```
tank-battle/
```

## 🧩 游戏规则

1. 操控你的坦克，消灭屏幕上所有的敌方坦克。
2. 保护底部的基地（老鹰），基地被击中则游戏结束。
3. 你共有 3 条生命，全部耗尽则游戏结束。
4. 消灭敌方坦克可获得分数，通关额外奖励 500 分。
